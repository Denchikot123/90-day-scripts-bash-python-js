## 📖 About the project

An intensive 90-day challenge to create pentest-scripts and learn languages for automation

**Goal:** Learning through practice, mistakes, and creating working tools.

## 🗓️ Marathon structure

| Phase | Days | Language | Focus |
|------|-----|------|-------|
| **1** | 1-30 | Bash | System automation |
| **2** | 31-60 | Python | Network intelligence |
| **3** | 61-90 | JavaScript | Web exploits |
| **4** | 90+ | Bash + Py + JS | Final project |

## 📁 Repository structure

### 🖥️ PC Setup

- **OS:** Kali linux (based)

- **Tools:** Python 3.8+, Node.js 16+, Bash 5.0+

## 🚀 Quick Start

```bash
# Cloning a repository
git clone https://github.com/spiral/90days-pentest-scripts.git
cd 90days-pentest-scripts

# Setting rights to Bash scripts
chmod +x 01_bash_30_days/*.sh

# Running
./01_bash_30_days/day_01_system_info.sh
```
